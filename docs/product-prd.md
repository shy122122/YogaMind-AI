# YogaMind AI 产品说明 PRD

## 1. 产品定位

YogaMind AI 是一款面向 C 端瑜伽零基础用户的移动端 H5 AI 瑜伽陪练 Demo。它不是医疗康复产品，而是运动健身辅助工具，核心目标是帮助用户在家练习时获得更清晰、更温和、更及时的动作反馈。

## 2. 目标用户

- 没有瑜伽基础，不知道动作是否标准的新手。
- 不愿意或暂时无法承担线下私教费用的用户。
- 跟视频练习时缺少反馈、担心做错动作受伤的用户。
- 想在家进行 8-10 分钟轻量运动的人群。

## 3. 用户痛点

- 私教费用高，入门成本高。
- 跟练视频无法判断用户动作是否正确。
- 新手容易因为频繁纠错产生焦虑。
- 手机全身入镜时，人离屏幕远，看不清提示。
- 独自练习缺少陪伴和正向反馈。

## 4. 产品目标

- 让用户第一次打开就知道怎么开始。
- 用本地姿态识别提供实时反馈，降低隐私顾虑。
- 用温和提示替代强警告，减少被监考感。
- 完成从课前准备、课中跟练、课后总结到打卡分享的闭环。
- 作为实习作品集，体现产品思维、前端能力、AI 工程能力和端侧 CV 理解。

## 5. 核心流程

```text
进入首页
  -> 选择练习目标
  -> AI 生成课表或进入离线演示
  -> 摄像头站位校验
  -> 标准示范 + 实时跟练
  -> 姿势识别与温和纠错
  -> 完成练习
  -> AI 总结与打卡海报
```

## 6. 关键功能

### 6.1 课前准备

- 展示“本地识别、AI 定制课表、温和纠错”三个核心卖点。
- 新手引导说明手机摆放、站位距离和语音提醒。
- 提供演示模式，方便无摄像头或面试场景快速展示。

### 6.2 跟练过程

- 左侧或浮层展示标准动作示范图。
- 摄像头画面作为主视觉，Canvas 绘制人体骨骼点。
- 根据目标动作计算关键关节角度。
- 当姿势偏差持续 1.5 秒后才触发提醒。
- 当动作类型不匹配时，优先提示用户回到正确起始姿势。
- 远距离模式下放大动作名、倒计时和一句核心提示。

### 6.3 语音陪练

- 语音语气应短、轻、鼓励。
- 同一句或同类提示 10 秒内不重复播放。
- 用户可一键静音。
- 语音应服务于练习节奏，而不是制造压力。

### 6.4 课后总结

- 展示练习时长、标准率、提醒次数。
- 给出主要进步和下次建议。
- 生成适合分享的打卡海报。

## 7. AI 能力说明

LLM 不负责实时姿态识别。实时识别由端侧 CV 完成。

LLM 的作用是：

- 根据用户目标生成结构化课程。
- 生成动作说明、要领提示和温和话术。
- 根据练习结果生成个性化课后总结。

这样的分工可以避免大模型参与毫秒级实时判断，保证低延迟和隐私安全。

## 8. 边界与风险

- 不提供医疗诊断和康复处方。
- MVP 阶段仅支持单人、无遮挡、光线较好的场景。
- 高风险动作不作为强纠错对象。
- MediaPipe 判断存在误差，所有反馈应保持“建议”口吻。
- 手机远距离看屏问题需要通过大字模式和语音持续优化。

## 9. 成功标准

- 新用户 3 分钟内能理解产品价值。
- 手机端可以从准备页走到总结页。
- 演示模式不依赖摄像头和后端。
- 面试官能看出项目同时覆盖前端、AI、CV 和产品设计。
